## Notes Making App

## Project Introduction
The Notes Making App is a simple Android application that allows users to create, save, and manage their personal notes easily. This application is developed as a mini project for the Mobile Application Development course.

## Project Details
- Project Name: Notes Making App
- Platform: Android studio
- Programming Language: Java
- User Interface: XML
